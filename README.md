### 2.1. Клонирование репозитория
```bash
git clone --recursive https://github.com/mazhugich-labs/xarm_ros2-playground.git
git submodule update --init --recursive
git pull --recurse-submodules
```

### 2.2. docker build
```bash
./docker.sh build
```

### 2.3. docker run
```bash
./docker.sh run
```

### 2.4. docker enter
```bash
./docker.sh enter
```

### 2.5. docker stop
```bash
./docker.sh stop
```
